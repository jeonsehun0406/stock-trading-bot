# 대형주 자동매매 봇

한국투자증권 KIS API 기반 자동매매 시스템.
위험 회피형 전략(대형주 + RSI 저가매수 + 뉴스필터)을 무인 서버에서 실행합니다.

---

## 📂 파일 구성

### 실행 (Python)
| 파일 | 역할 |
|------|------|
| `trading_bot.py` | **실전 봇 본체.** KIS API 주문 + 안전장치 6개 + 알림 |
| `universe.py` | **유니버스(거래대상) 스크리닝.** 대형주만 남기고 `universe.json`으로 저장 (오프라인 도구, 아래 참고) |
| `strategies.py` | **매매 전략 모듈.** RSI/이동평균/볼린저/돌파/MACD 5종 |
| `notifier.py` | 카카오톡·텔레그램 실시간 매매 알림 |
| `news_filter.py` | 뉴스 감성분석 필터 (Claude API, 매수 직전 악재 종목 스킵) |
| `backtest_pro.py` | 전략 검증 백테스트 (기본 vs 개선 비교) |
| `compare_strategies.py` | 5개 전략 성과 한번에 비교 |

### 화면 (브라우저로 열기)
| 파일 | 역할 |
|------|------|
| `dashboard.html` | 봇 운영 상태 대시보드 (자산·보유·매매내역, `bot_state.json` 실데이터 연동) |
| `strategy_simulator.html` | 전략별 매매 방식 비교 시뮬레이터 |

**`dashboard.html`은 반드시 로컬 서버로 열어야 합니다.** 파일 탐색기에서 더블클릭(`file://`)해서
열면 브라우저 보안 정책(CORS) 때문에 `bot_state.json`을 읽지 못하고 "아직 봇을 실행한 기록이
없습니다" 안내만 보입니다 (직접 확인함). 아래처럼 실행하세요.
```bash
cd stock_bot
python -m http.server
# 브라우저에서 http://localhost:8000/dashboard.html 열기
```

## 🚀 시작 순서

### 1단계 — 설치
```bash
pip install python-kis python-dotenv pandas numpy matplotlib yfinance finance-datareader requests anthropic
```

### 2단계 — 전략 이해하기 (실제 돈 X)
- `strategy_simulator.html`을 브라우저로 열기 → 각 전략이 어떻게 매매하는지 눈으로 확인
- `python compare_strategies.py` → 5개 전략 성과 비교 (실제 데이터)
- `python backtest_pro.py` → 기본 전략 상세 검증

**여기서 어떤 전략이 좋은지 데이터로 확인하세요.**

### 3단계 — 설정
```bash
cp .env.example .env
# .env 파일 열어서 KIS API 키, 텔레그램/카톡 토큰 입력
```
- KIS 키 발급: apiportal.koreainvestment.com
- 반드시 `KIS_VIRTUAL=true` (모의투자)로 시작
- 매매 전략은 `.env`의 `BOT_STRATEGY` 값으로 선택 (rsi/ma_cross/bollinger/breakout/macd, 기본값 rsi)

### 3-1단계 — 유니버스(거래대상) 생성
```bash
python universe.py
```
- 한국(FinanceDataReader)·미국(S&P500 + yfinance) 상장종목 전체를 시가총액·거래대금 기준으로
  스크리닝해 `universe.json`에 저장합니다 ("대형주만" 원칙 — 한국 시총 1조원↑, 미국 시총 100억달러↑
  + 유동성 하한).
- `trading_bot.py`는 시작할 때 `universe.json`이 있으면 자동으로 읽어 한국 매매 대상 종목을
  교체합니다. 파일이 없으면 하드코딩된 기본 10종목으로 안전하게 동작합니다.
- ⚠️ 봇이 스스로 재실행하지 않습니다. **주기적으로(예: 월 1회) 사람이 직접 재실행**해서
  최신 시총 순위를 반영하세요. 매매 대상이 바뀌는 민감한 파일이라 봇 실행과 의도적으로 분리했습니다.
- (미국 유니버스는 아직 실제 매매 로직에는 연결돼 있지 않습니다 — 다음 작업인 미국 주식 지원에서 사용 예정.)

### 4단계 — 모의투자 (가짜 돈, 최소 2주)
```bash
python trading_bot.py
```
- 카톡/텔레그램으로 알림 오는지 확인
- `logs/` 폴더에서 매매가 의도대로 되는지 확인
- 서킷브레이커·중복주문방지 작동 확인

### 5단계 — 실전 (검증 끝난 뒤에만)
- `.env`에서 `KIS_VIRTUAL=false`
- **소액부터** 시작

### 6단계 — 미국 주식 활성화 (선택)
1. **KIS 앱(또는 홈페이지)에서 원화를 달러로 미리 환전**해두세요. python-kis에는 자동환전
   기능이 없어서, 봇이 원화 현금으로 미국 주식을 사려고 시도하지 않습니다 — 반드시 사람이
   먼저 환전해야 합니다.
2. `.env`에서 `ENABLE_US_TRADING=true`로 변경
3. `python universe.py`로 `universe.json`에 미국 유니버스("us" 목록)가 이미 채워져 있는지 확인
   (없으면 자동 생성됨)
4. 이후엔 봇이 한국 스캔에 이어 미국 대형주도 함께 스캔·매매합니다. 원화 예수금과 USD
   예수금은 완전히 분리해서 관리하며(한쪽 현금으로 다른 시장 종목을 사지 않음), 보유종목
   슬롯(`max_positions`, 기본 5)은 한국+미국 합산 기준으로 공유합니다.
5. 미국은 "언제든 체결되는 시장가" 주문이 없어(장개시/장마감 조건부만 지원) 매수는
   현재가+0.5%, 매도는 현재가-0.5%의 지정가로 주문합니다(사실상 즉시체결 시장가처럼
   동작하게 하기 위한 슬리피지 버퍼 — `trading_bot.py`의 `US_LIMIT_SLIPPAGE` 상수로 조정
   가능). 값이 너무 크면 불리한 가격에 체결되고 너무 작으면 체결이 안 될 수 있어 대형주
   기준으로 넉넉한 0.5%를 기본값으로 뒀습니다.
6. 로그와 대시보드에서 미국 매매는 🇺🇸 표시/"(USD)" 표기로 한국 매매와 구분됩니다.

### 7단계 — 장후시간외(종가) 매수 활성화 (선택)

1. `.env`에서 `ENABLE_CLOSING_TRADE=true`로 변경.
2. ⚠️ **이 기능은 모의투자에서 검증이 불가능합니다.** KIS 공식 "장후시간외" 주문조건은
   python-kis 라이브러리가 API 호출 전에 바로 거부합니다("모의투자는 해당 주문조건을
   지원하지 않습니다") — `KIS_VIRTUAL=false`(실전투자)로 전환한 뒤에만 실제로 동작합니다.
   반드시 다른 안전장치·전략 검증이 끝난 뒤, 소액으로 먼저 확인하세요.
3. 정규장(15:30) 마감 후 15:40~16:00 KST에만 주문이 접수되므로, 이 시간대에도 봇이
   실행되도록 스케줄러(작업 스케줄러/crontab)에 트리거를 추가해야 합니다
   (`서버_무인실행_가이드.md` 참고). 이 시간대에 봇이 안 돌면 이 기능은 그냥 조용히
   아무 일도 하지 않습니다.
4. 한국 종목에만 적용됩니다(미국은 이 주문조건 자체가 없음). 매도(손절/익절)에는 적용하지
   않았습니다 — 위험회피 원칙상 손절을 장마감까지 늦추면 안 되기 때문에, 매도는 항상
   기존처럼 신호가 뜨는 즉시 지정가/시장가로 실행됩니다.
5. 장후시간외 주문은 접수 직후엔 아직 체결 전이라(그날 종가 확정 후 순차 체결), 다른
   주문처럼 바로 잔고를 재조회해 체결 여부를 확인하지 않습니다. 대시보드·로그엔 "접수"로만
   표시되고, 실제 체결 여부는 다음날 첫 스캔의 잔고 조회에서 확인됩니다.

## ⚠️ 꼭 알아둘 것

1. **이 봇은 수익을 보장하지 않습니다.** 전략 검증(2단계)이 가장 중요합니다.
2. **모의투자(4단계)를 반드시 거치세요.** 실전 직행은 도박입니다.
3. **`.env` 파일은 절대 공유·업로드 금지.** API 키가 유출되면 계좌가 위험합니다.
4. **레버리지·인버스는 넣지 않았습니다.** 위험 회피 목표에 맞지 않기 때문입니다.
5. 하락장 대비 = 인버스가 아니라 **현금 보유**입니다. 봇의 추세 필터가 자동으로 처리합니다.

## 🔧 안전장치 (trading_bot.py 내장)

1. 중복 주문 방지 — 같은 종목 하루 1회 (재시작해도 유지)
2. 서킷브레이커 — 일일 손실 -5% 시 당일 매매 중단
3. 주문 재시도 — 네트워크 오류 대응
4. 전체 로그 — 모든 매매·에러 기록
5. 봇 다운 알림 — 죽으면 즉시 통보
6. 설정 분리 — API 키를 코드와 분리
7. 뉴스 감성분석 필터 — 매수 직전 Claude API로 악재 종목 스킵 (보조 안전장치, fail-open)
8. 부분체결 감지 — 매수/매도 주문 성공(예외 없음)해도 잔고를 재조회해 실제 체결 수량을 대조.
   - 매수 0주 체결: 재시도 가능하게 남김 (`guard.mark`/기록 안 함)
   - 매수/매도 부분체결: `day_trades`·알림에 요청량이 아닌 **실제 체결량**만 기록
   - 매도 부분체결: `guard.mark`를 호출하지 않아 잔여 수량에 손절/익절이 계속 적용되게 함
9. 장 미개장 시 즉시 스킵 — `KisMarketNotOpenedError`는 재시도해도 의미 없으므로 재시도 없이 바로 로그 남기고 넘어감
10. 매도 실패 긴급 알림 — 재시도까지 다 실패하면(손절/익절 미실행) 로그뿐 아니라 카톡/텔레그램으로 즉시 통보
11. USD 예수금 없으면 미국 매수 자동 스킵 — `ENABLE_US_TRADING=true`여도 KIS 앱에서 환전을
    안 해뒀으면(USD 예수금 0원) 에러 없이 조용히 스킵되고, 로그·대시보드에 "환전 필요"로
    사유가 남습니다. 원화 현금과 USD 예수금은 완전히 분리해서 관리하므로 원화로 미국 주식을,
    USD로 한국 주식을 사는 일은 없습니다.
12. 켈리 포지션 사이징 — 매수 예산을 균등분배 대신 **최근 30건 실현손익 기반 1/4 켈리
    비중**으로 계산(`KellyTracker`, `logs/kelly_history.json`에 영구 저장). 거래 이력이
    5건 미만이면 자동으로 균등분배(1/`max_positions`)로 시작하고, 비중은 항상 최소 5%~최대
    25%로 제한됩니다. 한국(원화)·미국(USD) 매매는 같은 켈리 비중(w)을 공유하되 실제 예산은
    각자의 현금 풀(`cash_pool`)에서만 계산해 통화가 섞이지 않습니다.
